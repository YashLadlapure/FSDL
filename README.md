# FSDL Assignment 5 - React UI

## Aim
Design and develop an interactive user interface using React.

## Problem Statement
Build a Student Info Form using React with form validation.

## Features
- Collects Name, Email, Phone, Date of Birth, and Address
- Validates all fields on submit
- Highlights empty/invalid fields in red
- Shows submitted data on success

## Tech Stack
- React (Hooks - useState)
- CSS3

## File Structure
```
src/
  components/
    DataForm.jsx
  App.js
  App.css
```

## How to Run
```bash
npm install
npm start
```
App runs at http://localhost:3000
